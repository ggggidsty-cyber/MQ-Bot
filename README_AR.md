# بوت MQ

الأوامر في شات MQ النصي:
- `شغل اسم الأغنية`
- `وقف`

## الإعداد
1. في Discord Developer Portal > Bot فعّل Message Content Intent.
2. امنح البوت: View Channel, Send Messages, Read Message History, Connect, Speak.
3. انسخ `.env.example` إلى `.env`.
4. أدخل توكن البوت في DISCORD_TOKEN، ومعرّف الشات النصي في TEXT_CHANNEL_ID، ومعرّف الروم الصوتي في VOICE_CHANNEL_ID.
5. شغّل `npm install` ثم `npm start`.

للتشغيل 24 ساعة ارفع المشروع إلى استضافة تدعم Node.js 20 أو Docker كخدمة مستمرة، وأدخل المتغيرات الثلاثة في إعدادات الأسرار/Environment Variables.

لا تشارك التوكن مع أي شخص. البوت لا ينشئ حساب الاستضافة أو يضيف نفسه للسيرفر تلقائيًا. إعادة الاتصال محاولة وليست ضمانًا إذا أوقفت الاستضافة أو منعته صلاحيات الإدارة. تشغيل الأغاني يعتمد على توفر المصدر وقيوده الحالية؛ استخدم مصادر مسموحًا لك بتشغيلها.
